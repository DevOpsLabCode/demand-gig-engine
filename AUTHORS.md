## Attribution convention

Source files include an author header and a purpose statement. Markdown documents include the same author, organization, and website metadata near the title. Generated build output, dependency code, and binary image/PDF contents are not modified solely to embed source comments.

## Contributions

Future contributors should preserve existing attribution while adding themselves through normal commit history, pull-request records, and a documented contributor section when appropriate. Attribution does not replace a software license or define legal ownership rights.
