## Executive result

The updated package passed every dependency-free validation available in this environment. The application dependency installation was attempted in an isolated virtual environment, but the sandbox package mirror returned no Django distributions and outbound package-registry DNS is blocked. Therefore, the complete Django/Allauth pytest suite, Vite production build, Checkov, Bandit, pip-audit, and npm audit were not falsely reported as local passes. They remain configured for GitHub Actions and for an internet-connected development environment.

The previous GitHub application baseline succeeded with **84 tests plus 7 subtests and 99.37% coverage**. The final package adds expanded social-auth and ownership tests, so a new GitHub commit is required for the definitive updated count.

## Reproduce all tests

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
./scripts/run_all_tests.sh
```

For GitHub, push the package as a **new commit**. The application matrix, security jobs, CodeQL, dependency review, coverage artifacts, and security reports will run automatically.
